## Мета

Переставити кроки майстра так, щоб одразу після «Джерело трафіку» відкривався блок Підготовки Meta (кампанії / групи оголошень / крео), а вже за ним ішла Декомпозиція з розгалудженням на кожну обрану ціль.

## Новий порядок кроків у сайдбарі

```text
0. Ніша
1. Джерело трафіку
2. Підготовка реклами Meta     ← новий уніфікований крок (кампанії + + Додати ціль)
3. Декомпозиція                ← перша точка розгалудження на кожну ціль
4. Куди йдуть ліди
5. Інтеграція
6. Продажі
7. Retention
8. Результат
```

Кроки «Ціль оптимізації» та «Деталізація» більше не існують як окремі пункти сайдбару.

## Що робить + «Додати ціль» у блоці Підготовки

- Відкриває той самий двоколонковий пікер, що зараз стоїть у кроці «Ціль оптимізації»: зліва основна ціль (`CAMPAIGN_GOALS`), справа під-ціль (`AWARENESS_TYPES / TRAFFIC_TYPES / ENGAGEMENT_TYPES / SALES_TYPES / LEAD_TYPES`).
- Одне натискання + = одна нова ціль. Для `leads` користувач обирає конкретний тип лідгену (Whatsapp / Instant Form / тощо). Дублікати блокуються.
- Після підтвердження — в межах Підготовки з'являється нова «Кампанія» з порожніми групами оголошень і кнопкою «+ група», як зараз.
- Видалення цілі — крестиком у шапці кампанії, з тим самим `pendingRemoveLeadType`-діалогом попередження (щоб не втратити декомпозицію/інтеграцію/крео).
- Формат воронки (колишній крок «Деталізація») для ніші `Інфобізнес` показується inline всередині картки кампанії — компактний селект «Формат воронки», без окремого кроку.
